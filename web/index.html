Rehearse the interview with no one listening.

Local Interviewer runs adaptive practice interviews with an interviewer called Astra. The model, the speech recognition and the voice all run on your own machine, and every transcript stays in a local database.

01 / Try it

The real app, in offline mode

This is the project's own React app. A JavaScript port of the back end's offline path answers it in your browser: the question bank, the follow-up rules and the fallback scoring. I checked the port against the real FastAPI back end over 120 interviews and 1,824 comparisons, with no differences. Answers are typed here; Ollama, Whisper and voice need the local install.

    03 / Scoring

    Evidence or it does not count

    With a model, a separate evaluator returns weighted dimensions with quoted evidence. The back end recomputes the overall score itself, removes any quote that is not word for word from your answers, and lowers confidence where evidence is missing. Without a model, a limited fallback score is used.

    The evidence check

    Candidate answer Quotes the evaluator returned

      Spacing and capital letters are ignored. Anything else must match exactly.

      The fallback score

      Used when no model is connected. It looks only at how many words your answers average.

      04 / Voice and privacy

      Speech that never leaves the machine

      The browser's built-in speech features are not used, because some send audio to the cloud. Recording and playback take turns, and you always review a transcript before it is sent.

      05 / Setup

      Install it for the full experience

      Needs Git, Node.js 22, uv and FFmpeg. Python 3.12 is fetched by uv. Nothing large is downloaded until you ask.

      macOS (Apple silicon)

      git clone https://github.com/SparshSunilNaik/Local-Interviewer.git
cd Local-Interviewer
./setup.sh
./start.sh

      Then add the model and on-device speech recognition:

      ollama pull qwen3:8b
cd backend
uv sync --group stt-apple

      Open http://127.0.0.1:5173. Whisper medium.en (about 1.5 GB) downloads on the first transcription. ./stop.sh stops only the app's own processes.

      Windows (PowerShell)

      git clone https://github.com/SparshSunilNaik/Local-Interviewer.git
cd Local-Interviewer
.\scripts\setup-windows.ps1
.\scripts\start-windows.ps1

      Portable speech recognition with faster-whisper:

      cd backend
uv sync --group stt-portable

      The macOS voice is not available on Windows, so use text mode until a local Kokoro voice is set up. Close the app's terminals to stop it.
